1. АКТУАЛЬНІСТЬ ТЕМИ
   Актуальність розробки зумовлена критичною необхідністю забезпечення високого рівня ізоляції та безпеки під час динамічного виконання неперевіреного користувацького коду (untrusted code) у хмарних середовищах. Існуючі системи оцінки технічних компетенцій та колаборативного програмування часто вразливі до атак типу Remote Code Execution (RCE) або стикаються з проблемами вертикального масштабування при паралельній обробці ресурсомістких завдань компіляції. Супутньою інженерною проблемою є забезпечення низьких затримок (low-latency) та консистентності даних при синхронізації стану редактора між кількома клієнтами в умовах конкурентного доступу.

Використання хмаро-орієнтованої (Cloud-Native) мікросервісної архітектури, ізольованих ефемерних контейнерів та асинхронних черг повідомлень дозволяє комплексно вирішити ці проблеми. Такий підхід гарантує fault tolerance, жорстке квотування апаратних ресурсів (CPU, RAM, Timeout) та стабільність системи під високим навантаженням (запобігання вичерпанню ресурсів), що робить тему дослідження технічно та практично затребуваною.

2. ОБ'ЄКТ ДОСЛІДЖЕННЯ
   Процес безпечної обробки, виконання довільного програмного коду та синхронізації даних у системах колаборативного програмування реального часу.

3. ПРЕДМЕТ ДОСЛІДЖЕННЯ
   Методи контейнеризації, архітектурні патерни подієво-орієнтованої взаємодії (Event-Driven Architecture, Worker Queue) та алгоритми вирішення конфліктів конкурентного доступу (CRDT/OT), що застосовуються для оркестрації ізольованих середовищ та забезпечення low-latency синхронізації.

4. МЕТА РОБОТИ
   Проєктування та розробка мікросервісної вебплатформи для алгоритмічного тестування та парного програмування шляхом застосування методів ефемерної контейнеризації та патернів асинхронної взаємодії для підвищення рівня безпеки (нейтралізації RCE-загроз), забезпечення відмовостійкості інфраструктури та мінімізації мережевих затримок у процесі спільного редагування.

5. ЗАВДАННЯ ПРОЄКТУ
   Проаналізувати існуючі архітектурні рішення, протоколи передачі даних та алгоритмічні підходи до побудови систем безпечного виконання коду (sandboxing) і колаборативного редагування.

Обґрунтувати вибір технологічного стека, архітектурних патернів взаємодії мікросервісів та інфраструктурних рішень для реалізації ізольованого ядра виконання (Code Execution Engine).

Спроєктувати мікросервісну архітектуру системи, ER-моделі баз даних та API-контракти з використанням абстракцій моделі C4 та діаграм UML.

Розробити алгоритмічне забезпечення критичних вузлів: механізм динамічного провіжінінгу Docker-контейнерів із квотуванням ресурсів та систему синхронізації стану редактора.

Реалізувати програмні модулі платформи, налаштувати централізовану авторизацію (SSO/RBAC) та спроєктувати схему розгортання інфраструктури з використанням Docker Compose та брокера повідомлень RabbitMQ.

Провести інструментальний аудит коду, модульне тестування (Unit Tests) підсистеми алгоритмічної верифікації та перевірку системи обмеження частоти запитів (Rate Limiting).

Дослідити ефективність впроваджених архітектурних рішень та здійснити науково-практичну апробацію результатів роботи (підготовка матеріалів для фахової публікації або конференції).
