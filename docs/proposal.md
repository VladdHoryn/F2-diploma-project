1. Тема проєкту

**UA:** Розробка мікросервісної вебплатформи для алгоритмічного тестування та парного програмування в реальному часі. 

**EN:** Development of a Microservice Web Platform for Algorithmic Testing and Real-Time Pair Programming.

2. Актуальність та проблематика 

Оцінка технічних компетенцій розробників у віддаленому форматі потребує платформ, що поєднують спільне редагування коду з його безпечним виконанням. Існуючі рішення часто є фрагментованими або не забезпечують достатнього рівня ізоляції при виконанні неперевіреного коду користувачів. 

Ключова інженерна проблема проєкту полягає у нейтралізації загроз безпеці (Remote Code Execution) під час запуску довільного коду. Реалізація вимагає проєктування високонавантаженої архітектури для динамічного провіжінінгу ізольованих (sandboxed) середовищ із жорстким квотуванням ресурсів (CPU/RAM, Timeout). Супутнім викликом є забезпечення low-latency синхронізації стану редактора між кількома клієнтами з вирішенням конфліктів конкурентного доступу (concurrency control).

3. Архітектурне бачення продукту 

Продукт проєктується як **Cloud-Native мікросервісна система**, що складається з клієнтського інтерактивного IDE та серверної інфраструктури з ізольованим кластером виконання коду (Code Execution Engine). Архітектура базується на подієво-орієнтованому підході (Event-Driven Architecture). Для забезпечення відмовостійкості та горизонтального масштабування використовується патерн Worker Queue: брокер повідомлень асинхронно маршрутизує ресурсомісткі завдання компіляції на ізольовані worker-вузли, розвантажуючи основний API.

4. Ключовий функціонал та інженерні рішення (Core Features)

**Ізольоване ядро виконання (Code Execution Engine):** Автоматизований оркестратор ефемерних Docker-контейнерів. Забезпечує безпечну компіляцію та виконання коду з використанням механізмів обмеження споживання пам'яті, процесорного часу та блокування зовнішнього мережевого трафіку.

**Колаборативний редактор реального часу:** Підсистема управління кімнатами з використанням протоколу WebSockets/STOMP. Застосування алгоритмів вирішення конфліктів (CRDT/OT) для консистентної синхронізації тексту та позицій курсорів між клієнтами.

**Підсистема алгоритмічного тестування:** Модуль автоматизованої верифікації рішень за допомогою прихованих наборів модульних тестів (Unit Tests) з подальшим профілюванням просторової та часової складності алгоритмів (Big O metrics).

**Асинхронна обробка та Rate Limiting:** Розподілення процесів прийому HTTP-запитів та безпосереднього виконання коду через брокер повідомлень. Використання in-memory сховища для обмеження частоти запитів (Rate Limiting), що запобігає вичерпанню ресурсів (DDoS).

**Identity and Access Management (IAM):** Інтеграція централізованого провайдера авторизації (SSO) на базі протоколів OAuth2/OpenID Connect для реалізації рольової моделі доступу (RBAC).

**Аудит та персистенція даних:** Збереження історії виконання, логів компіляції та автоматична генерація метрик технічних сесій.

5. Технологічний стек та інфраструктура

**Backend:** Java 17+, Spring Boot (Web, Security, Data JPA, WebSockets/STOMP).

**Frontend:** React, Monaco Editor.

**Бази даних та кешування:** PostgreSQL (персистентне зберігання сутностей), Redis (кешування сесій, Rate Limiting). Версіонування схеми БД за допомогою Flyway.

**Identity Provider:** Keycloak (управління користувачами та RBAC).

**Архітектурні патерни:** Microservices, Event-Driven Architecture, API Gateway, Worker/Task Queue.

**DevOps та інфраструктура:** Docker, Docker API, Docker Compose (контейнеризація та sandboxing), RabbitMQ (брокер повідомлень). CI/CD пайплайни для автоматизації тестування та розгортання. Базова спостережуваність (Observability) за допомогою логування метрик виконання.
